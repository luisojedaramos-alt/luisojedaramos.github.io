Política de privacidad

Esta aplicación la usa únicamente su titular, Luis Manuel Ojeda Ramos, con su propia cuenta de Google.

Accede a su Gmail para leer notificaciones con documentos adjuntos y a su Google Drive para archivarlos en las carpetas de sus expedientes. Los datos no se venden, no se ceden a terceros ni se usan con fines publicitarios.

El registro de documentos y plazos se guarda en una base de datos privada alojada en la Unión Europea. Para leer el contenido de los documentos se utiliza la API de Anthropic, que no los utiliza para entrenar modelos.
